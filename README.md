## ⚙️ Installation & Requirements

```bash
# Clone this repository
$ git clone https://github.com/volthz001/Data-Exploration.git
$ cd Data-Exploration

# Install Python packages
$ pip install -r requirements.txt
```

Required packages include:
- pandas
- matplotlib
- seaborn
- jupyter
- numpy
