# Data Exploration

This repository contains Jupyter notebooks for performing exploratory data analysis (EDA) on various datasets.

---

## 📓 Contents

- `Retail_Sales_EDA.ipynb` — Notebook analyzing retail sales data
- `Cleaning_and_Visualization.ipynb` — Data cleaning and visualization examples

---

## ⚖️ Requirements
Install dependencies with:
```bash
pip install -r requirements.txt
```

---

## 📐 Getting Started
To launch the notebooks:
```bash
jupyter notebook
```

---

## 📌 Preview
You will find visualizations such as:
- Bar charts
- Line plots
- Correlation heatmaps
